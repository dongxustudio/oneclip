# OneClip v1.0.0 — 使用说明书

## 简介

OneClip 是一个桌面文本片段管理器。把常用的文字（问候语、地址、签名、常用回复、模板等）提前存进去，需要时一键复制，到任何地方 `Ctrl+V` 粘贴即可。

程序常驻系统托盘，不占任务栏空间。全局热键 `Ctrl+Shift+V` 随时呼出。应用未启动时，按 `Ctrl+Shift+V` 也能一键打开。

---

## 安装

1. 双击 `OneClip-Setup-1.0.0.exe`
2. 选择安装目录（默认 `%LOCALAPPDATA%\Programs\OneClip`）
3. 勾选创建桌面快捷方式
4. 安装完成 → 程序自动启动，托盘出现羽毛笔图标

---

## 基本使用

### 启动与唤出

| 操作 | 效果 |
|------|------|
| 开机自动启动 | 右键托盘 → 勾选 `Start with Windows` |
| 手动唤出 | 单击托盘图标，或按 `Ctrl+Shift+V`（任意位置） |
| 隐藏窗口 | 按 `Ctrl+Shift+V`，或单击托盘，或点窗口 ✕ |
| 应用未运行时唤起 | 按 `Ctrl+Shift+V`，Windows 自动启动 OneClip |

> 窗口的 ✕ 是隐藏到托盘，不是退出。

### 创建片段

1. 唤出窗口，点击右上角 **New** 按钮（或按 `Ctrl+N`）
2. 填写：
   - **Title** — 片段的显示名称，如"公司地址"
   - **Group** — 分组名（可选）。输入框为空时自动弹出已有分组列表供选择；打字时列表收起可手动输入新名称；点右侧 `▾` 随时展开全部分组任选
   - **Content** — 要复制的文本内容
3. 按 `Ctrl+Enter`（或在 Content 中直接按 `Enter`）保存

### 复制片段

- 点击卡片右下角 **Copy** 按钮 → 内容进入剪贴板
- 或用键盘：`↑↓` 选中卡片 → 按 `Enter`
- 按钮短暂显示 **Copied**（绿色）表示成功
- 到目标窗口 `Ctrl+V` 粘贴

### 编辑片段

- 双击卡片，或点卡片上的 **Edit**
- 修改后 `Ctrl+Enter` 保存（或在 Content 字段中直接按 `Enter`）

### 删除片段

- 点卡片上的 **Del** → 弹出确认框 → 点 **Delete**
- 或按 `Enter` 确认，`Esc` 取消

## 分组管理

### 创建分组

芯片栏最右侧点 `+` → 弹出 New Group 弹窗 → 输入名称 → Enter 或点 Create。空分组会显示在手风琴视图中。

### 浏览分组

- **手风琴模式**（默认全部折叠）：所有分组以折叠面板展示，点击分组名展开/折叠
- **芯片过滤**：搜索框下方的分组标签栏，点击只看该分组的内容
- **All**：点击 "All" 芯片或清除搜索，回到手风琴全览
- **空分组**：点击芯片进入空分组时，显示引导页（No snippets in "xxx" + New Snippet 按钮）

### 右键菜单

右键分组标题（手风琴）或分组芯片，弹出菜单：

| 选项 | 作用 |
|------|------|
| New Snippet | 打开编辑器，Group 字段预填该分组名 |
| Rename | 分组名变为可编辑输入框，Enter 确认，Esc 取消 |
| Delete | 弹出确认框，可选择将片段移入 Uncategorized / 移入其他分组 / 永久删除 |

### 分组排序

拖拽分组标题栏可调整分组显示顺序，芯片栏会同步更新。

### 跨组移动

拖拽一张卡片到另一个分组的标题栏或卡片之间，即可改变其分组归属。

---

## 搜索

在顶部搜索框输入关键词，实时过滤匹配的片段。匹配范围：

- 标题
- 内容
- 分组名（匹配分组名时，该组全部片段都会显示）

`Esc` 或点清除按钮退出搜索。

---

## 键盘快捷键

### 全局

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+Shift+V` | 唤出/隐藏 OneClip（运行时）；启动 OneClip（未运行时） |

### 窗口内

| 快捷键 | 条件 | 作用 |
|--------|------|------|
| `Ctrl+N` | — | 新建片段 |
| `Ctrl+F` | — | 聚焦搜索框 |
| `Ctrl+Shift+E` | — | 导出片段 |
| `Ctrl+Shift+I` | — | 导入片段 |
| `Ctrl+Shift+D` | — | 更改数据存储目录 |
| `← →` | 焦点不在输入框 | 左右切换分组芯片 |
| `↑ ↓` | 已选中卡片 | 上下移动卡片高亮 |
| `Enter` | 有选中卡片 | 复制该卡片内容 |
| `Esc` | 有选中卡片 | 取消选中 |
| `Esc` | 搜索框有内容 | 清除搜索 |

### 编辑弹窗内

| 快捷键 | 条件 | 作用 |
|--------|------|------|
| `↓` | 在 Title 字段 | 跳到 Group 字段 |
| `↓` | 在 Group 字段 | 跳到 Content 字段 |
| `↑` | 在 Group 字段 | 跳回 Title 字段 |
| `↑` | 在 Content 光标在开头 | 跳回 Group 字段 |
| `Enter` | 在 Title 字段 | 跳到 Group 字段 |
| `Enter` | 在 Group 字段 | 跳到 Content 字段 |
| `Enter` | 在 Content 字段 | 保存（等同于 Ctrl+Enter） |
| `Shift+Enter` | 在 Content 字段 | 换行 |
| `Ctrl+Enter` | — | 保存并关闭 |
| `Esc` | — | 取消并关闭 |

**Group 下拉列表展开时**：

| 快捷键 | 作用 |
|--------|------|
| `↓ ↑` | 在分组列表中移动高亮 |
| `Enter` | 选中高亮分组，填入输入框 |
| `Esc` | 收起下拉列表 |

### 删除确认弹窗内

| 快捷键 | 作用 |
|--------|------|
| `Enter` | 确认删除 |
| `Esc` | 取消 |

## 托盘右键菜单

| 菜单项 | 作用 |
|--------|------|
| Show Window | 显示主窗口 |
| New Snippet | 显示窗口 + 打开新建弹窗 |
| Export Snippets | 导出全部片段为 JSON 文件 |
| Import Snippets | 从 JSON 文件导入片段（自动去重） |
| Change Data Folder... | 更换数据文件存储目录 |
| Start with Windows | 开关机自动启动 |
| Exit | 完全退出程序 |

## 数据管理

### 默认存储位置

```
C:\Users\<用户名>\AppData\Roaming\OneClip\data.json
```

### 更改存储位置

1. 右键托盘 → **Change Data Folder...**（或按 `Ctrl+Shift+D`）
2. 选择目标文件夹
3. 现有数据自动迁移到新位置
4. Toast 提示成功后即刻生效

之后所有数据读写都在新位置，备份文件 `data.json.bak` 也会自动生成在同一个目录。

### 备份

每次保存时自动创建 `data.json.bak` 备份。如需恢复，删除 `data.json`，将 `.bak` 重命名为 `data.json` 即可。

### 导出

- 托盘菜单 **Export Snippets** 或 `Ctrl+Shift+E`
- 生成可移植的 JSON 文件，包含所有片段

### 导入

- 托盘菜单 **Import Snippets** 或 `Ctrl+Shift+I`
- 自动跳过已存在的片段（按 ID 去重）
- 导入成功后列表自动刷新

## 窗口置顶

点击标题栏左侧图钉图标，窗口将始终置顶。再次点击取消。状态会自动记住。

## 退出程序

右键托盘 → **Exit**。

> 直接点窗口 ✕ 只是隐藏，不是退出。

---

## 提示

- Content 字段无论多长都会完整复制，卡片上只预览前两行
- 标题为空时，自动取内容前 20 个字符作为标题
- 搜索框右侧 × 清除搜索，回到手风琴全览
- 选中卡片后可以用 `↑↓` 键浏览，`Enter` 键比鼠标点 Copy 更快
- 卡片右侧的 Edit/Del 按钮在鼠标悬停时才显示，保持界面干净
- 右键分组标题或芯片可以重命名、删除、在该组新建片段
- Group 字段为空时自动弹出全部分组；打字时列表收起；点 `▾` 随时展开
- 编辑弹窗遮罩不会因从其他窗口切回而误关闭
